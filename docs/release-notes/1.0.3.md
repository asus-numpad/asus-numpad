这一版把「机型表里没有的机器」当成正经需求来做，顺手补齐了上一版留下的显示与排障问题。

机型表之外的触摸板现在可以自己配：新增的「扩展」页签管四件事——自定义键表、点亮报文、压感切换、全局热键，全部落在原来那份 `asus-numpad.json` 里。键表能继承内置表，也能按列数自动排布；点亮报文可以整条改写，留一个字节当档位占位符；压感切换与热键默认关闭，开了才生效。命令行也看得见了：`layout` 末尾列出已装的自定义布局，`check` 多一段打印扩展开关。

图形界面这批改得比较多：卡片分栏、深浅色跟随系统、页签换成分段控件；标签列改左对齐并统一图标槽，右缘不再参差；每个可配置项都挂上悬浮说明，长句子放进两层气泡里。截图工具链也跟着补了漏，离屏环境下悬停气泡现在拍得出来。

另外修掉三处会把人带偏的排障输出：`--lang` 与配置里的 `language` 之前根本没生效，坏配置提示会印两遍，LED 报文报错里漏出 `{err}` 字面量。常驻循环去掉每帧堆分配、点灯两条报文分开送、读失败不再一碰就退；管道被 `head` 提前关掉时也不再 `Abort trap`。

最后是分发侧：`tools/build-cross.sh` 一条命令出 Windows `exe` 与 Linux ELF，`tools/verify-extend.sh` 的 22 项只读检查接进 CI，脚本里 `$VAR` 后紧跟中文标点导致 `unbound variable` 的写法全仓扫净并加了静态检查。

完整变更见 [CHANGELOG.md](https://github.com/asus-numpad/asus-numpad/blob/main/CHANGELOG.md)。
