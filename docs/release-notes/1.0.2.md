双屏机型（`GVM` / `GVM_A` / `NVM`）不再标「未解析」：参数本就照官方 inf 录入，三张键表归为同族，`gx550` / `ux582` 从 `unsupported` 转为可用（仍需 `--allow-unverified`）。支持级别的说法改成实话，`unsupported` 指「没有键位依据」而不是「网格不同」。另附按官方配置逐条核验的机型兼容表，以及 `install.sh` 一条命令加源安装。
